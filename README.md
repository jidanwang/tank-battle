# 坦克大战 · Tank Battle

一个使用原生 HTML5 Canvas 编写的经典坦克大战游戏，单文件即可运行，无需任何依赖。

## 玩法

- 控制你的坦克，消灭全部 **20 辆敌军坦克** 即可过关，之后进入更难的下一关
- 保护基地（🦅 老鹰）不被摧毁，否则游戏结束
- 砖墙可被击毁，钢墙需满级火力才能击穿
- 敌人被击毁后有一定概率掉落道具

## 操作

| 动作 | 按键 |
| --- | --- |
| 移动 | 方向键 / WASD |
| 开火 | 空格 / J |
| 开始 / 重新开始 | Enter |
| 静音 | M |

手机上会自动显示虚拟方向键与开火按钮。

## 道具

| 图标 | 效果 |
| --- | --- |
| ★ | 提升火力等级（更快 → 双发 → 可击穿钢墙）|
| 🛡 | 获得护盾（短时间内无敌）|
| ❄ | 冰冻场上所有敌人 |
| ♥ | 增加一条生命 |
| ✹ | 手雷，清除场上所有敌人 |

## 运行

直接用浏览器打开 `index.html` 即可游玩。也可部署到 GitHub Pages：

```
仓库 Settings → Pages → Source: Deploy from a branch → Branch: main
```

## 技术

- 原生 JavaScript + Canvas，无第三方库
- Web Audio API 实时生成音效
- 支持键盘与触屏操作
- 三个内置关卡，通关后循环并逐步提升难度
